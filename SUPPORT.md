# Getting help

- **Installing or running it:** [gubernaut.com/install](https://gubernaut.com/install), then the
  [questions hub](https://gubernaut.com/faq).
- **A question that is not a bug:** [Discussions](https://github.com/thegubernaut/gubernaut/discussions)
  on the main repository.
- **A bug:** an [issue](https://github.com/thegubernaut/gubernaut/issues) on the main repository,
  with the version and a minimal reproduction.
- **A security problem:** never in public. See [SECURITY.md](SECURITY.md).
- **Anything else:** [contact@gubernaut.com](mailto:contact@gubernaut.com).

Gubernaut is free and self-hosted. There is no paid support tier, and questions are answered in
public where others can find the answer.
